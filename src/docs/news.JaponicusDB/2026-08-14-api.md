### PomBase Application Programming Interface (API)

[![API diagram](assets/newsfeed/2026-08-13-pombase-api-small.png){.screenshot .newsfeed-inline-thumbnail loading="lazy" width=20%}](assets/newsfeed/2026-08-13-pombase-api-small.png)

JaponicusDB now has an [API](https://en.wikipedia.org/wiki/API) for
programmatic access to *S. japonicus* data.  The following data
types can be retrieved by ID using the API:

 - gene details
 - GO annotation (by gene ID or term ID)
 - Phenotype / genotype annotation (by gene or term ID)

An ID mapping tool is also available to convert:

  - cerevisiae, human or *S. pombe* gene IDs to *japonicus* IDs via orthologs
  - UniProtKB accessions (e.g. "O60150") to *japonicus* IDs
