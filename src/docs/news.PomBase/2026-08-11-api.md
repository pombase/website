### PomBase Application Programming Interface (API)
<!-- newsfeed_thumbnail: pombase-logo-32x32px.png -->

PomBase now has an [API](https://en.wikipedia.org/wiki/API) for
programmatic access to the latest pombe data.  The following data
types can be retrieved by ID using the API:

 - gene details
 - GO annotation (by gene ID or term ID)
 - Phenotype / genotype annotation (by gene or term ID)

An ID mapping tool is also available to convert:

  - cerevisiae, human or S. japonicus gene IDs to pombe IDs via orthologs
  - UniProtKB accessions (e.g. "O60150") to pombe IDs

Full API documentation and examples:
[https://www.pombase.org/documentation/api](https://www.pombase.org/documentation/api)

All data available via this API can also be downloaded in bulk.
Visit the [Datasets page](/datasets) for information about the files
available in each release.

An API is now also available for JaponicusDB. \
Documentation: [https://www.japonicusdb.org/documentation/api](https://www.japonicusdb.org/documentation/api)
